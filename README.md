# hd_nofos

R processing code, resulting data files, and R app for running a Shiny dashboard to display posted notices of funding opportunity (NOFOs) of interest to NICHD from grants.gov.

The `nofo_scanning.r` file contains code for downloading, analyzing, and summarizing NOFO data from the simpler.grants.gov API. The script generates the files located in the "data" folder. The `app.r` file creates the dashboard.
